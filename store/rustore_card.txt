MatchLab — карточка RuStore

Краткое описание
MatchLab — приложение футбольной аналитики: реальные матчи из открытого API и собственный математический прогноз исхода.

Полное описание
MatchLab показывает матчи Английской Премьер-лиги и Ла Лиги, считает силу команд по рейтингу Elo и вероятности голов по распределению Пуассона.

Это не букмекер и не игра на деньги:
• нет ставок и коэффициентов;
• нет пополнения и вывода средств;
• виртуальные баллы начисляются только за правильный бесплатный прогноз (+10).

Пользователь может сохранить свой прогноз на исход матча (П1 / X / П2), изменить или удалить его до начала игры. Аватар можно сделать на камеру; если разрешение отклонено, приложение продолжает работать.

Возрастной рейтинг
0+ / для всех возрастов. Контент: спортивная статистика, без насилия и азартных игр.

Разрешения
• Интернет — загрузка календаря и результатов матчей из TheSportsDB.
• Камера — необязательное фото для аватара. Отказ не мешает пользоваться приложением.

Комментарий для модератора
Учебное Android-приложение. Аналитика футбола и бесплатные прогнозы без ставок, платежей и вывода призов. Камера нужна только для аватара. applicationId: ru.matchlab.app

Скриншоты
Сделайте 3 кадра: список матчей, аналитика матча с вероятностями, экран прогнозов или профиля.
