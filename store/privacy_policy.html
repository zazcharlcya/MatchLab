Политика конфиденциальности

MatchLab — учебное приложение футбольной аналитики. Мы не принимаем ставки, не проводим платежи и не выводим призы.

Какие данные хранятся

  • Имя в профиле — только на этом телефоне.
  • Фото аватара — только если вы сами сделали снимок камерой; файл лежит в памяти приложения.
  • Ваши прогнозы и виртуальные баллы — только на этом телефоне, в локальной базе.

Срок хранения

Данные хранятся на устройстве, пока установлено приложение. Отдельного облачного хранения нет.

Что уходит в интернет

  • Календарь и результаты матчей загружаются с открытого API OpenLigaDB.
  • Эмблемы клубов могут подгружаться с адресов, которые присылает это API (часто Wikimedia).

Камера

Нужна только для необязательного аватара. Отказ в разрешении не мешает пользоваться матчами, моделью и прогнозами.

Чего нет

Нет регистрации, рекламы, трекеров, аккаунта в облаке и передачи данных третьим лицам. Мы не продаём информацию и не создаём профили для рекламы.

Порядок удаления

Удалите приложение — вместе с ним сотрутся имя, фото, прогнозы и баллы на этом устройстве.

Контакты

Ответственный за обработку данных — разработчик MatchLab. По вопросам напишите через карточку приложения в RuStore.
